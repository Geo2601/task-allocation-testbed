# Данные к статье

Итог всех расчётов, по которым построены таблицы и рисунки статьи. Из этих файлов
`python -m experiments.article` за несколько минут воспроизводит таблицы 1–5, рисунки 1–4
и сверяет числа текста. Как получить эти файлы заново — в разделе «Полный расчёт с нуля» README.

| Файл | Что в нём | Где в статье |
|---|---|---|
| `all.csv.gz` | 12 500 тестовых примеров × методы: разрывы до эталона и другие показатели | разделы 4–5, рис. 3–4, табл. 2 и 4 |
| `reference_quality.csv.gz` | что доказано в эталоне каждого примера основного эксперимента и проверок «объём» и «база в центре» | раздел 2, табл. 1 |
| `exact_limits.csv` | пробный расчёт предела точного решения: 65 примеров, лимит 600 с, 12 потоков | раздел 2 |
| `front_example.json` | полный эталон и решения методов одного примера (M = 4, N = 24, L0, общая база, разнотипная группа) | раздел 5.1, рис. 2 |
| `mechanism.csv` | целостность скоплений, неравномерность загрузки, простаивающие аппараты (медианы; M = 8, ρ = 6, однородная группа) | раздел 5.3, табл. 3 |
| `mechanism_purity.csv` | то же для проверки «один тип в скоплении» | раздел 5.6 |
| `gaca_check.csv.gz` | сверка с GACA в условиях авторов: 100 полей на каждое M = 5, 10, 15, 20 | раздел 5.7, табл. 5 |
| `skfu_check.csv` | сверка с методом секторов в условиях авторов: куб 100 × 100 × 100, 100 точек, 100 карт на каждое M | раздел 5.7 |

Данные по каждому примеру (точки, полный эталон, все решения задач эталона) лежат в отдельных
JSON-файлах, около 40 МБ в архиве; в репозиторий они не входят и могут быть приложены к выпуску
(Releases) отдельным архивом.

## all.csv.gz — столбцы

Одна строка — один пример и один метод.

| Столбец | Значение |
|---|---|
| `key` | имя примера: `<набор>_<уровень>_M<аппаратов>_r<задач на аппарат>_<старт>_<hom/het>_rep<повтор>` |
| `prefix` | набор: `main` — основной эксперимент; проверки устойчивости: `volume` — трёхмерная постановка, `center` — база в центре поля, `clusters_half` и `clusters_double` — скоплений M/2 и 2M, `purity` — один тип задач в скоплении |
| `rep` | номер повтора, 0–49; повторы 0–6 каждого десятка — обучающая часть для правила выбора, 7–9 — отложенная |
| `level` | уровень скученности: L0 — равномерное поле, L1–L4 — всё более сильные скопления |
| `M`, `rho`, `N` | число аппаратов, задач на аппарат, задач (N = M·ρ) |
| `start` | `base` — общая база с возвратом; `scattered` — рассредоточенный старт без возврата |
| `hetero` | разнотипная группа (`True`) или однородная (`False`) |
| `dim`, `base_pos` | размерность поля (2 или 3) и положение базы (`corner` — угол, `center` — центр) |
| `R` | показатель скученности Кларка — Эванса (меньше 1 — скопления) |
| `ref_kind` | эталон: `exact` — точный фронт, все задачи доказаны; `exact_partial` — точный, часть задач не доказана за лимит; окончание `_lean` — облегчённый эталон (только минимумы S, Λ и F_w); `best_known` — лучшее известное решение; `best_known+exact_S` — то же с доказанным минимумом S |
| `ref_wall` | время расчёта эталона, с |
| `workers` | потоков CP-SAT на пример |
| `method` | метод: `greedy` — жадный; `cbba` — CBBA, ставка по приросту пути; `kmeans_hungarian` — k-means + венгерский метод; `gaca` — GACA; `skfu` — секторы. Варианты для сверок: `cbba_tdr` (ценность задачи убывает со временем прибытия), `cbba_tdr_marginal` (то же по приросту, настройка авторов GACA), `gaca_route` (другое прочтение функции Φ; только при N ≤ 24), `gaca_cut_end` (другое правило разрезания цепочек), `greedy_round_robin` (аппараты выбирают задачи по очереди) |
| `S`, `Lam` | суммарный путь и время выполнения (длина самого длинного маршрута) после единого решателя маршрутов |
| `raw_S`, `raw_Lam` | то же по маршрутам, которые построил сам метод (если метод их строит) |
| `idle` | число простаивающих аппаратов |
| `rounds`, `messages` | число раундов и сообщений аукционных алгоритмов |
| `wall` | время работы метода, с |
| `g_S`, `g_Lam` | разрыв по суммарному пути и по времени выполнения: S/S* − 1 и Λ/Λ* − 1 (доли, не проценты) |
| `g_w50` | разрыв по взвешенному критерию F_0,5 (равный вес); `g_w25`, `g_w75` — веса пути 0,25 и 0,75 |
| `eps` | мультипликативный ε-индикатор до эталонного фронта |
| `converged` | сошёлся ли аукционный алгоритм |

## reference_quality.csv.gz — столбцы

`S_proven`, `Lam_proven` — доказан ли минимум S и Λ; `W_proven` — доказаны ли все три минимума F_w,
`W_share` — доля доказанных; `Lam_gap` — для недоказанного минимума Λ расхождение найденного
решения с нижней оценкой (доля); `bk_S_over_opt` — при N = 48: насколько лучшее известное S выше
доказанного минимума (доля).
